- **The population at raw borough labels, and what the `Unknown`/`N/A` merge does to it.** 122 rows (month × origin label × destination label) with billable trips; 9 of them have an unresolved label at both ends, 37 at one end. Merging the two labels into one `Unresolved` group gives 104 rows, and moves no trip. — `with t as (select date_trunc('month', f.pickup_datetime)::date as m, o.borough_name as ob, dz.borough_name as db, count(*) as trips from core.fct_trip f join core.dim_zone o on f.pickup_zone_key = o.zone_key join core.dim_zone dz on f.dropoff_zone_key = dz.zone_key where f.pickup_datetime >= timestamp '2024-01-01' and f.pickup_datetime < timestamp '2024-04-01' and f.is_billable group by 1,2,3) select count(*) as rows_total, count(*) filter (where ob in ('Unknown','N/A') and db in ('Unknown','N/A')) as both_unresolved, count(*) filter (where (ob in ('Unknown','N/A')) <> (db in ('Unknown','N/A'))) as one_side_unresolved, count(distinct case when ob in ('Unknown','N/A') then ob end) as unresolved_values_origin, count(distinct case when db in ('Unknown','N/A') then db end) as unresolved_values_dest from t`

- **The leaving-borough share, on the denominator the requirement records** (the origin borough's trips resolved to a named borough at both ends). - **The per-row shares close.** Over 21 origin-borough-months, the named-borough destination shares sum to 1.000000 each (min 1.0, max 1.0). — `with t as (select date_trunc('month', f.pickup_datetime)::date as m, case when o.borough_name in ('Unknown','N/A') then 'Unresolved' else o.borough_name end as ob, case when dz.borough_name in ('Unknown','N/A') then 'Unresolved' else dz.borough_name end as db, count(*) as trips from core.fct_trip f join core.dim_zone o on f.pickup_zone_key = o.zone_key join core.dim_zone dz on f.dropoff_zone_key = dz.zone_key where f.pickup_datetime >= timestamp '2024-01-01' and f.pickup_datetime < timestamp '2024-04-01' and f.is_billable group by 1,2,3), d as (select m, ob, db, trips, sum(trips) filter (where db <> 'Unresolved') over (partition by m, ob) as denom from t), s as (select m, ob, sum(trips*1.0/nullif(denom,0)) as share_sum from d where db <> 'Unresolved' group by 1,2) select count(*) as origin_months, round(min(share_sum),6) as min_sum, round(max(share_sum),6) as max_sum from s`

- **No origin-borough-month has a zero resolved denominator**, so the null-share path exists only for `Unresolved` destination rows. — `with t as (select date_trunc('month', f.pickup_datetime)::date as m, case when o.borough_name in ('Unknown','N/A') then 'Unresolved' else o.borough_name end as ob, case when dz.borough_name in ('Unknown','N/A') then 'Unresolved' else dz.borough_name end as db, count(*) as trips from core.fct_trip f join core.dim_zone o on f.pickup_zone_key = o.zone_key join core.dim_zone dz on f.dropoff_zone_key = dz.zone_key where f.pickup_datetime >= timestamp '2024-01-01' and f.pickup_datetime < timestamp '2024-04-01' and f.is_billable group by 1,2,3) select m, ob, sum(trips) filter (where db <> 'Unresolved') as resolved_trips, sum(trips) as all_trips from t group by 1,2 having coalesce(sum(trips) filter (where db <> 'Unresolved'),0) = 0 order by 1,2`
