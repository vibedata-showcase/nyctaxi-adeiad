### The two builds measure different populations

- Q1 2024 totals of `agg_trip_zone_daily` against `finance.mart_daily_zone_revenue`, read from the Domain warehouse on 2026-11-25 — `select sum(trip_count) as trips, round(sum(total_revenue),2) as revenue, (select sum(trip_count) from finance.mart_daily_zone_revenue) as fin_trips, (select round(sum(total_revenue),2) from finance.mart_daily_zone_revenue) as fin_revenue from agg.agg_trip_zone_daily` — 97,184 / 2,597,120.92 (ops) against 95,958 / 2,629,185.82 (report).
- JFK Airport in both, same session — `select zone_name, sum(trip_count) as trips, round(sum(total_revenue),2) as revenue from agg.agg_trip_zone_daily where zone_name = 'JFK Airport' group by 1 union all select zone_name, sum(trip_count), round(sum(total_revenue),2) from finance.mart_daily_zone_revenue where zone_name = 'JFK Airport' group by 1` — 4,261 / 329,766.06 (ops) against 4,120 / 337,711.05 (report).
- The gap is exactly the non-billable trips, and nothing else — `select f.is_billable, count(*) as trips, round(sum(f.total_amount),2) as total_amount, round(sum(f.fare_amount),2) as fare, round(sum(f.tip_amount),2) as tip from core.fct_trip f where f.pickup_date >= date '2024-01-01' and f.pickup_date < date '2024-04-01' group by 1 order by 1` — false: 1,226 trips, −32,064.90; true: 95,958 trips, 2,629,185.82. 95,958 + 1,226 = 97,184 and 2,629,185.82 − 32,064.90 = 2,597,120.92.

### Both builds are internally correct

- Each relation recomputed from `core.fct_trip` and `core.dim_zone`, compared per grain — `with recomputed as (select f.pickup_date, z.zone_natural_key as loc, count(*) as all_trips, round(sum(f.total_amount),2) as all_rev, count(*) filter (where f.is_billable) as bill_trips, round(sum(f.total_amount) filter (where f.is_billable),2) as bill_rev from core.fct_trip f join core.dim_zone z on f.pickup_zone_key = z.zone_key where f.pickup_date >= date '2024-01-01' and f.pickup_date < date '2024-04-01' group by 1,2) select (select count(*) from recomputed r join agg.agg_trip_zone_daily a on a.pickup_date=r.pickup_date and a.pickup_location_id=r.loc where a.trip_count<>r.all_trips) as agg_count_mismatch, (select count(*) from recomputed r join agg.agg_trip_zone_daily a on a.pickup_date=r.pickup_date and a.pickup_location_id=r.loc where round(a.total_revenue,2)<>r.all_rev) as agg_rev_mismatch, (select count(*) from recomputed r join finance.mart_daily_zone_revenue m on m.trip_date=r.pickup_date and m.pickup_location_id=r.loc where m.trip_count<>r.bill_trips) as fin_count_mismatch, (select count(*) from recomputed r join finance.mart_daily_zone_revenue m on m.trip_date=r.pickup_date and m.pickup_location_id=r.loc where round(m.total_revenue,2)<>r.bill_rev) as fin_rev_mismatch, (select count(*) from recomputed) as recomputed_rows` — 0, 0, 0, 0; 7,997 recomputed rows.

### A billable zone-day aggregate reproduces the report exactly

- The intended new aggregation, simulated before any edit, compared column by column to the report — `with billable as (select f.pickup_date as trip_date, z.zone_natural_key as pickup_location_id, count(*) as trip_count, sum(f.fare_amount) as fare_revenue, sum(f.tip_amount) as tip_revenue, sum(f.total_surcharges) as surcharge_revenue, sum(f.tolls_amount) as toll_revenue, sum(f.total_amount) as total_revenue from core.fct_trip f join core.dim_zone z on f.pickup_zone_key=z.zone_key where f.pickup_date>=date '2024-01-01' and f.pickup_date<date '2024-04-01' and f.is_billable group by 1,2) select (select count(*) from billable) as simulated_rows, (select count(*) from billable b left join finance.mart_daily_zone_revenue m on m.trip_date=b.trip_date and m.pickup_location_id=b.pickup_location_id where m.trip_date is null) as sim_only, (select count(*) from finance.mart_daily_zone_revenue m left join billable b on m.trip_date=b.trip_date and m.pickup_location_id=b.pickup_location_id where b.trip_date is null) as fin_only, (select count(*) from billable b join finance.mart_daily_zone_revenue m on m.trip_date=b.trip_date and m.pickup_location_id=b.pickup_location_id where b.trip_count<>m.trip_count or round(b.fare_revenue,2)<>round(m.fare_revenue,2) or round(b.tip_revenue,2)<>round(m.tip_revenue,2) or round(b.surcharge_revenue,2)<>round(m.surcharge_revenue,2) or round(b.toll_revenue,2)<>round(m.toll_revenue,2) or round(b.total_revenue,2)<>round(m.total_revenue,2)) as value_diffs` — 7,961 simulated rows; 0 rows only in the simulation, 0 only in the report, 0 value differences.
